Install and update Fauteuil on Mac

Choose the right macOS release, install Fauteuil and its runtime, then test playback with a local video.

1. Choose a release for your Mac

Check your macOS version under Apple menu → About This Mac. The current universal ZIP supports macOS 15 and later on Apple Silicon and Intel. On macOS 13 or 14, use Fauteuil 1.3.1 and its setup instructions. That version requires manual dependency installation.

Download Fauteuil for macOS 15 and later

2. Open or update the app

Unzip the archive, open Fauteuil.app and choose Installer dans Applications. Quit any running copy before updating. When an older copy is installed, confirm the in-place update. Fauteuil offers to open an existing installation that is at least as recent.

The app is ad hoc signed. If macOS asks for confirmation, see Apple’s instructions for opening apps safely.

3. Set up the runtime

When prompted, choose Installer les outils. The app downloads and verifies its runtime from GitHub. Allow around 145 MB of downloads and up to 300 MB of storage before adding videos. If setup fails, check access to GitHub and free disk space, then reopen Fauteuil. Runtime details in French.

4. Test a local video

Go to Mes vidéos → Ajouter des vidéos and select an MP4 you can play on your Mac. This test needs no Google account. For subscriptions or personal playlists, see Google setup in French.
