Connect YouTube and your Google account to Fauteuil

Set up YouTube Data API and a desktop OAuth client to view your own YouTube subscriptions and playlists in Fauteuil on Mac.

When you need a Google account

Connect Google to see subscriptions and playlists from your account. Local videos and public playlist URLs work without account setup. Fauteuil uses the subscriptions exposed by the API. It does not reproduce YouTube’s personalized home feed.

Enable YouTube Data API

Open Compte Google in Fauteuil and choose Ouvrir YouTube Data API. Select or create a Google Cloud project and enable the API.

Create your desktop OAuth client

  1. Choose Configurer Fauteuil, name the app and select the External audience.
  2. Add the Google account you will use to the test users listed under Audience.
  3. Create an OAuth client of type Desktop app and download its JSON file.
  4. Choose Importer le fichier Google et se connecter in Fauteuil and authorize read access to YouTube in your browser.

If Google declines authorization

Check that you selected the same account as the test user. Confirm that YouTube Data API is enabled in the OAuth client’s project and that the imported file is for a desktop application.

macOS Keychain stores the client secret and refresh token. Keep your OAuth JSON file private. Google OAuth documentation for desktop apps.
