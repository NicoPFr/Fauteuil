# Kit de présentation de Fauteuil

Fauteuil rassemble les vidéos d’un Mac et les playlists YouTube dans une médiathèque personnelle. On retrouve ses séries, on reprend là où on s’était arrêté et on garde les vidéos de son choix pour le hors ligne.

- [Dépôt public](https://github.com/NicoPFr/Fauteuil)
- [Site de Fauteuil](https://nicopfr.github.io/Fauteuil/)
- [Version pour macOS](https://github.com/NicoPFr/Fauteuil/releases/latest)
- [Icône](../assets/icon.png)
- [Capture de l’accueil](../assets/home.jpg)
- [Capture d’une playlist](../assets/playlists.jpg)

Les captures présentent une bibliothèque fictive et des illustrations originales. L’application est disponible en français sur macOS. Le code est publié sous licence MIT.

## Texte d’annonce prêt à partager

**Fauteuil met tes vidéos à portée de télécommande, même hors ligne.**

Une app pour Mac qui réunit tes fichiers vidéo, tes abonnements et tes playlists YouTube. Reprends une lecture, passe à l’épisode suivant ou garde une sélection pour le prochain trajet. La version actuelle est disponible pour macOS, sur Apple Silicon et Intel. [Télécharger Fauteuil](https://github.com/NicoPFr/Fauteuil/releases/latest)
