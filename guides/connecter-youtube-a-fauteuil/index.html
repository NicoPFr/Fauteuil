Connecter YouTube et son compte Google à Fauteuil

Configure YouTube Data API et le client OAuth de Fauteuil pour retrouver les abonnements et playlists de ton compte sur Mac.

Quand connecter un compte Google

Connecte Google pour retrouver les abonnements et les playlists de ton compte. Tu peux lire tes vidéos locales et ajouter une playlist YouTube publique par son lien sans configurer de compte. La synchronisation récupère les abonnements. Elle ne reprend pas l’accueil personnalisé de YouTube.

Activer YouTube Data API

Dans Fauteuil, ouvre Compte Google, puis clique sur Ouvrir YouTube Data API. Crée ou sélectionne ton projet dans Google Cloud et active l’API.

Créer le fichier de connexion

  1. Depuis Fauteuil, ouvre Configurer Fauteuil. Donne un nom à l’application et choisis l’audience Externe.
  2. Dans Audience, ajoute à la liste des utilisateurs test le compte qui servira à lire tes abonnements.
  3. Crée un client OAuth de type Application de bureau et télécharge le fichier JSON du client.
  4. Dans Fauteuil, choisis Importer le fichier Google et se connecter, puis autorise l’accès en lecture à YouTube dans ton navigateur.

Si Google refuse l’autorisation

Sur l’écran d’autorisation, vérifie que le compte sélectionné est bien celui ajouté comme utilisateur test. Vérifie également que YouTube Data API est activée dans le même projet que ton client OAuth et que le fichier importé correspond à un client pour application de bureau.

Le Trousseau macOS protège le secret client et le jeton de renouvellement. Garde le fichier JSON de ton client dans tes dossiers privés. Documentation Google OAuth pour applications de bureau.
