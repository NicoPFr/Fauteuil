# Security

Do not put Google OAuth JSON files, refresh tokens, cookies, private media or
library databases in issues or pull requests. Fauteuil stores credentials in
macOS Keychain and uses a loopback-only server; it is not intended for LAN hosting.

To report a vulnerability, use the repository's **Security → Report a vulnerability**
(private vulnerability reporting). Please include a minimal reproduction without
personal data. There is no commercial support or response-time guarantee.
